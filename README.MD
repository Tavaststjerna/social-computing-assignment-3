# MiniSocial – Coding Assignment 3

Eeli Tavaststjerna – Social Computing 2026–2027, University of Oulu.

Added features: post recommendations, introduction threads (Chapter 5, Design Claim 19) and a private practice area (Chapter 5, Design Claim 24). Developed with ChatGPT assistance.

## Run on Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Open http://127.0.0.1:8080 in your browser.
